## ✨ Overview  
In today’s fast-paced financial world, manually verifying loan applications is time-consuming and error-prone. This project leverages Machine Learning algorithms to build an intelligent system that predicts whether a loan applicant is eligible or not based on key financial and personal attributes. The goal is to reduce risk, increase efficiency, and automate loan approval decisions.

📊 Dataset Insights

The model is trained on features such as Applicant Details (Gender, Marital Status), Employment Status, Income (Applicant & Co-applicant), Loan Amount & Term, Credit History (most important feature), and Property Area.

🤖 Models Implemented

Logistic Regression ⭐⭐⭐⭐☆ | Decision Tree ⭐⭐⭐☆☆ | Random Forest ⭐⭐⭐⭐⭐ | Support Vector Machine ⭐⭐⭐⭐☆
🏆 Best Model: Random Forest (Highest Accuracy)

📈 Evaluation Metrics

Accuracy Score, Confusion Matrix, Precision, Recall, and F1 Score are used to evaluate model performance
